Mot de passe mis à jour.

Vous pouvez supprimer ce compte gérant (par exemple, le compte par défaut créé via creer-gerant.html) une fois qu'un autre compte existe. Assurez-vous d'avoir créé un autre accès gérant avant (Paramètres → Comptes gérant, plus bas) : si c'est le seul compte, le supprimer vous bloquera hors de l'espace gérant.

État des données

Les données sont stockées sur Firebase Firestore et partagées en temps réel entre le site public et cet espace gérant, sur n'importe quel appareil. L'accès à cet espace est protégé par un compte (voir README pour créer/gérer les comptes gérant) ; pensez à durcir les règles Firestore avant l'ouverture réelle (voir firestore.rules).

Pixels & analytics

Le Meta Pixel et Google Analytics se branchent dans le <head> de index.html une fois le site déployé sur un vrai nom de domaine (ces scripts ne peuvent pas tourner correctement en test local en file://).
